# Managed Data

This directory contains extracts from the /r/teslore wiki listing files that are
more easily digestible by management software, including the site itself.

- `reddit.txt`: sorted list of all post identifiers in the collection. Taken
  directly from the index files, without any inspection against reddit proper.

- non-reddit external hosted stories: only _Pocket Guide to the Lore_ and
  _A Red Dusk Before Dawn_ remain accessible. They have been downloaded directly
  and stored in place of their original post to /r/teslore under an identifier.
  That identifier is _not_ in `reddit.txt`.
